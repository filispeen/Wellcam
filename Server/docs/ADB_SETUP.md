# Підключення по кабелю через ADB

Режим "USB (ADB)" у WinCam Server. Телефон слухає порт 11203, ПК підключається через `adb forward`. Мережа, tethering і драйвери RNDIS/NCM не потрібні.

## 1. Режим розробника на телефоні

1. Налаштування, Про телефон (About phone).
2. Сім разів натисни на "Номер збірки" (Build number). З'явиться повідомлення, що ти розробник.
3. Налаштування, Система, Для розробників (Developer options).
4. Увімкни "Налагодження по USB" (USB debugging).

На Xiaomi/Redmi/POCO додатково увімкни "Налагодження по USB (параметри безпеки)". На Samsung шлях: Налаштування, Про телефон, Відомості про ПЗ, Номер збірки.

## 2. ADB на ПК (Windows)

1. Завантаж SDK Platform-Tools з https://developer.android.com/tools/releases/platform-tools
2. Розпакуй, наприклад, у `C:\platform-tools`.
3. Додай цю папку в PATH: Параметри системи, Змінні середовища, Path, Створити.
4. Відкрий новий термінал і перевір: `adb version`.

## 3. Підключення телефону

1. Під'єднай телефон кабелем, який передає дані (не тільки заряджання).
2. На телефоні підтверди запит "Дозволити налагодження по USB?" і постав "Завжди дозволяти для цього комп'ютера".
3. Перевір на ПК: `adb devices`. У списку має бути пристрій зі статусом `device`.

## 4. Запуск стріму

1. У WinCam Server обери Connection: USB (ADB), натисни Start server.
2. На ПК виконай: `adb forward tcp:11203 tcp:11203`
3. ПК-клієнт підключається до `127.0.0.1:11203`.

`adb forward` треба повторювати після кожного перепідключення кабелю або `adb kill-server`. Для кількох телефонів: `adb -s <serial> forward tcp:11203 tcp:11203`, серійний номер видно в `adb devices`.

## Проблеми

- `unauthorized`: на телефоні не підтверджено запит. Відключи кабель, вимкни і знову увімкни "Налагодження по USB", під'єднай заново.
- `offline` або порожній список: `adb kill-server`, потім `adb devices`. Спробуй інший кабель або порт USB.
- Пристрій не видно у Windows: встанови OEM USB Driver виробника телефону.
- Клієнт підключився, але немає відео: переконайся, що сервер у статусі Listening до запуску клієнта, і що порт у `adb forward` збігається з 11203.
